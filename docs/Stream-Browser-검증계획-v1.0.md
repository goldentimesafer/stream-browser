# Stream Browser — 보안 및 인수시험 계획 v1.0

작성일: 2026-11-13 · 연결 문서: [개발 명세서](./Stream-Browser-iOS-개발명세서-v1.0.md)

> 개인 설치 전환에 따라 [v1.1 변경 명세](./Stream-Browser-개인설치-변경명세-v1.1.md)의 시험 기기 범위와 추가 설치·갱신 시험을 함께 적용한다. App Store 제출은 현재 필수 완료 조건이 아니다.

> [보완 기능 v1.2](./Stream-Browser-보완기능-v1.2.md)의 E01~08과 아래 B01~08·H01~05를 첫 개인 사용판에 적용한다. ID가 부여된 시험은 기본 49개, 개인 설치 7개, 보완 기능 8개, 백그라운드·HLS 13개로 총 77개다.

이 문서는 앞으로 구현할 앱의 시험 절차다. 현재 앱 구현·Xcode 빌드·실기기 시험을 수행했다는 보고서가 아니다. 표의 상태는 모두 **미실행**이며, 구현 후 결과와 증거를 기록해야 한다.

## 1. 시험 환경

- 최소 지원 iOS의 실제 지원 기기 1대, 중간 지원 버전 1대, 출시 시 최신 정식 iOS 기기 1대. 확보한 모델·메모리·OS 빌드·Xcode·앱 커밋을 기록한다.
- 시뮬레이터는 UI·단위·일부 네트워크 시험에 사용한다. Face ID, 기기 잠금, Data Protection, 저장공간, background 전송은 실기기를 필수로 한다.
- 개발사가 통제하는 HTTPS fixture 서버와 권리가 확보된 H.264/AAC MP4 3종: 작은 파일, 100MB, 1GB. 임의 제3자 미디어를 내려받아 fixture로 만들지 않는다.
- 정상 인증서, 만료/잘못된 호스트/자체서명 인증서, HTTP 전용 endpoint, 별도 리디렉션 호스트를 준비한다.
- `200`, `206`, `301/302/307/308`, `401/403`, `404`, `416`, `429`, `500/503`, 지연, 연결 끊기, 알 수 없는 크기, Range 미지원, ETag 변경 응답을 제공한다.
- 파일명 공격, MIME 불일치, HTML 오류 페이지, 잘린 MP4, 과대 크기, 중복 완료 이벤트를 재현할 fixture를 제공한다.
- 고유 방문 문자열·서명 토큰·파일명을 테스트용으로 만들고 앱 컨테이너·로그·DB에서 누출 여부를 찾는다. 실제 사용자 쿠키나 개인 영상을 쓰지 않는다.
- MITM 관찰이 필요하면 시험 기기에만 테스트 인증서를 구성하고 릴리스 앱의 인증서 검증 코드를 약화하지 않는다. 패킷·로그는 시험 전용 자료만 포함한다.

## 2. 판정과 증거

시험 결과는 Pass / Fail / Blocked / Not applicable로 기록한다. 미실행은 Pass가 아니다. 조건부 지원을 판정할 경우 사이트·OS·파일 형식별 범위를 명시한다.

모든 실행 기록에는 테스트 ID, 관련 요구사항, 빌드, OS/기기, 사전 조건, 실제 결과, 기대 결과, 증거 경로, 담당자, 실행일을 포함한다. 보안 검증은 릴리스와 같은 설정으로 다시 수행한다.

우선순위:

- **P0:** 개인정보·권한 경계·데이터 무결성 또는 핵심 탐색/저장 흐름. 실패 시 출시 차단.
- **P1:** 첫 버전 약속에 포함된 호환성·접근성·오류 복구. 지원 범위를 줄이거나 수정한 뒤 출시.
- **후속:** R2의 영상 후보 탐지 진입 조건.

## 6. 첫 버전 백그라운드·HLS 시험

보유 iPhone과 허가된 HTTPS 시험 출처로 실행한다. 시스템 종료와 사용자의 앱 전환 화면 강제 종료를 별개로 기록한다. 백그라운드 및 HLS 경로의 실패는 첫 개인 사용판 완료를 차단한다.

HLS 시험 출처에는 기본·선택 오디오와 자막이 있는 VOD, 라이브, 암호화 표시가 있는 테스트 목록, 세그먼트 누락, 미검증 하위 호스트 사례를 준비한다. 충분히 긴 공개 파일로 잠금 중 전송을 재현한다.

| ID | 절차 | 합격 기준 |
|---|---|---|
| B01 | 공개 직접 파일을 백그라운드로 저장하고 인증 필요 링크·서명 URL로 반복 | 검증된 무인증 URL만 작업 생성. 테스트 서버에 비공개 쿠키·인증 헤더·서명 토큰이 전달되지 않음 |
| B02 | 전송 중 홈 화면 전환, 화면 잠금, 시스템 종료 후 재실행 | 지원 조건에서 작업 진행·완료 확인. 고정 세션 ID와 작업 ID로 재연결하고 중복 항목 없음 |
| B03 | 전송 중 사용자가 앱 강제 종료 후 다시 열기 | 중단·재시도 상태가 실제와 일치. 자동 완료로 표시하지 않음 |
| B04 | 잠금 중 전송 완료, 콜백 종료 뒤 잠금 해제 | 일반 임시 파일은 콜백 안에서 보호 staging에 인수. 잠금 해제 후 검증하거나 안전한 인수 실패 시 재시도 안내 |
| B05 | HTTP 하향, 예상 밖 호스트, 허용 HTTPS 직접 링크 검증 | 제어할 수 없는 출처는 지원 경로에서 제외. ATS 적용과 응답 정책 검사, 실패 파일 폐기 확인 |
| B06 | 취소·전체 삭제 직후 완료 이벤트 도착 | 파일·상태·로컬 참조가 되살아나지 않음 |
| B07 | 오프라인, 네트워크 전환, iOS 전송 지연 | 대기와 실패 상태 구분. 취소 가능 |
| B08 | 비공개 세션 종료 후 공개 작업과 인증 작업 확인 | 비공개 작업과 인증 정보 정리. 별도로 승인한 공개 작업만 유지 |
| H01 | 검증된 VOD 저장 후 재실행·비행기 모드에서 재생·탐색 | 시스템 위치의 로컬 자산을 사용. 저장된 오디오와 선택 트랙을 오프라인에서 확인 |
| H02 | 라이브·DRM·지원되지 않는 키, HTTP·미검증 하위 출처 입력 | 지원 여부를 구분해 안내. 지원 정책을 충족한 소스만 오프라인 작업 시작 |
| H03 | HLS 전송 중 화면 잠금과 시스템 종료, 재연결 | 작업·로컬 참조 복구, 시스템 위치 유지, 잠금 중 콘텐츠 읽기와 재생 차단 |
| H04 | 일부 세그먼트 실패, 취소, 잠금 해제 후 삭제, 시스템 자산 누락 | 재생 가능 확인 후에만 저장 완료 표시. 실제 패키지·참조 정리 또는 누락 상태 표시 |

영상 자동 탐지는 후속 시험으로 진행한다. 교차 출처 iframe, 조작된 메시지, 이전 문서의 응답, 과대 메시지와 호출 폭주를 시험한다. 탐지 결과는 확인 화면의 후보로 표시하며 전송과 내보내기는 별도 사용자 동작으로 시작한다.
