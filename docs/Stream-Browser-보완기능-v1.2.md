# Stream Browser — 보완 기능 명세 v1.2

작성일: 2026-11-13 · 상태: 구현 요구사항, 아직 앱에 구현되지 않음

적용 문서: [기본 명세](./Stream-Browser-iOS-개발명세서-v1.0.md), [개인 설치 조건](./Stream-Browser-개인설치-변경명세-v1.1.md), [Brave 선별 결과](../reference/brave-media/README.md)

첫 버전은 **비공개 브라우저, 보호된 저장함, 직접 파일·백그라운드·HLS 다운로드, 오프라인 재생, 오류 복구**를 포함한다. 개인 설치와 보유 기기 검증은 v1.1을 따른다.

| 보호 설명 | 사이트·앱 보호 상태 표시 | HTTPS, 규칙 적용 여부, 비공개 세션, 앱 잠금 설정을 사실대로 표시 | 새 보완; 종합 보안 점수·근거 없는 차단 건수 표시 금지 |
| 유지관리 | 임시 파일 정리·업데이트 후 데이터 유지 | 완료·취소 후 관련 staging 정리; 비정상 종료 잔여물은 다음 실행에서 조정 | 기존 T16·S11·D02~04 유지 |

광고·추적 차단은 채택한 규칙이 적용되는 범위의 기능이다. 모든 광고·추적·피싱을 탐지한다고 표시하지 않는다. 규칙 소스와 라이선스가 선정·검증되기 전에는 기능 구현이 완료된 것으로 간주하지 않는다.

## 2. 추가 데이터 정책

- **중복 확인:** 전체 URL을 영속 색인에 넣지 않는다. R1은 현재 세션의 정확히 같은 요청과 기존 파일 메타데이터 기반의 중복 가능성만 안내한다. 제목·파일 크기가 같다는 이유만으로 전송을 강제 취소하지 않는다. 바이트 해시 기반 중복 판정은 후속 최적화다.
- **재생 위치:** 사용자가 설정을 켰을 때만 `mediaID + positionSeconds + updatedAt`을 로컬 보호 DB에 보관한다. 방문 URL은 저장하지 않는다. 파일 삭제와 함께 삭제하고, 설정을 끌 때 이전 위치 기록도 정리한다.
- **보호 상태:** 기본 화면은 네트워크 조회 없이 로컬 상태만 표시한다. 악성 사이트 평판 서비스를 새로 연결하려면 전송 데이터·제공자·실패 정책을 먼저 명세한다.
- **진단:** 오류 코드를 사용자에게 설명하되 쿠키·전체 서명 URL·개인 파일명·페이지 본문을 진단 로그로 남기지 않는다.
- **임시 내보내기:** 공유 시 필요한 사본만 생성하고 정상 종료 시 정리한다. 앱이 중단되어 남은 사본은 다음 실행에서 정리하며, 항상 즉시 정리된다고 약속하지 않는다. 보호 데이터 접근이 불가능하면 잠금 해제 후 정리한다.
- **접근성:** 배속·보호 상태·용량·다중 삭제도 VoiceOver와 큰 글씨에서 조작·확인이 가능해야 한다.

### 저장함과 재생기 연결

일반 영상은 앱의 보호 저장소에서 로컬 파일을 열고, HLS는 시스템이 저장한 오프라인 자산 참조를 연다. 두 항목 모두 저장함에서 선택하고 오프라인으로 재생한다. 일반 영상은 파일 앱이나 사진 앱으로 내보낼 수 있다. HLS는 앱 내 오프라인 자산으로 관리한다. 파일 또는 자산이 없으면 저장 상태를 갱신하고 다시 받기 동작을 표시한다. [Apple HLS 오프라인 저장 예제](https://developer.apple.com/documentation/avfoundation/using-avfoundation-to-play-and-persist-http-live-streams)

첫 버전 재생기는 시스템 `AVPlayer`와 `AVKit`을 사용한다. 기본 재생 화면, 탐색, 배속을 구성하고 저장된 HLS 트랙은 실제 오프라인 재생 결과로 검증한다. [Apple VideoPlayer](https://developer.apple.com/documentation/avkit/videoplayer)

| 오픈소스 후보 | 적용 조건 |
|---|---|
| VideoKit (MIT) | SwiftUI 재생 화면을 더 세밀하게 조정해야 할 때 검토한다. AVPlayer 기반이라 재생 가능한 코덱 범위는 기기의 AVFoundation에 따른다. 현재 패키지는 iOS 15 이상, Swift 도구 6.1을 선언한다. [소스](https://github.com/danielsaidi/VideoKit) · [패키지 정의](https://github.com/danielsaidi/VideoKit/blob/main/Package.swift) |
| MobileVLCKit (LGPL 2.1 이상) | 실제 사용 파일 중 AVFoundation으로 재생되지 않는 형식을 지원해야 할 때 검토한다. libVLC 바이너리의 통합, 재서명, 대상 파일 재생과 라이선스를 확인한다. HLS 오프라인 자산은 AVPlayer에서 연다. [VideoLAN 공식 저장소](https://github.com/videolan/vlckit) |

검토한 Brave `PlayerModel`은 BraveCore·Data·Playlist 등에 의존한다. 이 저장함은 별도의 로컬 재생 화면으로 구현한다. 오픈소스 후보는 조사 결과이며 현재 앱의 의존성으로 추가된 상태는 아니다. [Brave PlayerModel 원본](https://github.com/brave/brave-core/blob/b38bae283b5a99943d114655f76a495d901a68b0/ios/brave-ios/Sources/PlaylistUI/PlayerModel.swift)

## 3. 후속 기능

| 기능 | 추가 시점·조건 |
|---|---|
| 허가된 영상 후보 탐지·선택 | 직접 저장 흐름 완성 후. 원본 Brave JS를 그대로 넣지 않고 제한된 DOM 후보와 네이티브 검증으로 구성 |
| Wi-Fi 전용·셀룰러 허용 설정 | 해당 전송 엔진에서 공개 API로 실제 강제 가능한지 확인한 뒤 제공; 상태 관찰만으로 보장했다고 표시하지 않음 |
| 폴더·즐겨찾기·썸네일 보기 | 기본 저장함 완성 후. 썸네일도 보호·삭제·앱 잠금 정책 적용 |
| PiP·백그라운드 재생 | 보유 기기에서 검증하고 앱 잠금과의 충돌을 정의한 뒤 선택 기능으로 제공 |
| 독립 암호화 금고 | 별도 키 관리·복호화 스트리밍·복구 정책을 설계한 뒤 구현 |

VPN·AI·클라우드 동기화·사이트별 추출기는 현재 범위에 추가하지 않는다. 목적과 무관한 코드량·네트워크 경로를 늘리지 않고, 실제 사용에 필요한 보호와 편의를 우선한다.

## 4. 보완 인수시험

기본 49개 기능·보안 시험, 개인 설치 D01~07, 백그라운드 B01~08, HLS H01~05와 함께 다음 항목을 적용한다. 모두 미실행 상태다.

| ID | 절차 | 합격 기준 |
|---|---|---|
| E01 | 동일 요청을 두 번 저장, 제목만 같은 다른 영상 저장 | 중복 가능성 확인; 다른 영상을 임의 삭제·취소하지 않음 |
| E02 | 영상 여러 개 선택 후 삭제 취소·확정 | 대상·용량 표시, 취소 시 유지, 확정 시 관련 메타데이터 포함 삭제 |
| E03 | 보호 규칙 컴파일 실패·사이트 예외·새 세션 | 상태가 실제와 일치, 예외 자동 확대·재사용 없음 |
| E04 | 재생 위치 저장 켜기·재실행·끄기·파일 삭제 | 선택한 정책대로만 기록·복원·삭제 |
| E05 | 큰 파일 저장과 임시 파일 생성·취소 | 공간 표시 갱신, 기존 미디어 자동 삭제 없음 |
| E06 | 내보내기 취소·공유 완료·도중 앱 중단 | 정상 경로 정리, 중단 후 다음 실행에서 잔여물 정리 |
| E07 | URL 만료·인증 실패·공간 부족 각각 발생 | 원인별 행동 안내, 민감 정보 로그·화면 과다 노출 없음 |
| E08 | VoiceOver로 배속·보호 상태·용량·다중 삭제 조작 | 모든 핵심 기능 완료, 상태 변화 알림, 잠금 우회 없음 |

## 5. 구현 순서와 완료 조건

1. 비공개 브라우저·HTTPS·앱 잠금·가림·차단 규칙 적용 기반.
2. 직접 파일 저장·큐·검증·안전한 저장소·오류 복구.
3. 백그라운드 파일과 HLS 엔진, 시스템 이벤트 재연결, 저장함·오프라인 재생·삭제·내보내기.
4. 개인 설치·업데이트·갱신 데이터 유지와 전체 보안 시험.

위 단계는 작업 순서이며, 1~2단계만 끝낸 것을 완성된 첫 버전으로 제시하지 않는다. 보안 기능을 빼서 토큰을 줄이지 않고, 기존 요구사항 재사용·작은 파일 범위·자동 검증으로 반복 분석을 줄인다.
