# Stream Browser 수정 및 검증 v1.3

## 변경 내용

- 최종 파일 이동 전에 보호된 가져오기 기록을 남긴다. 이동 전/후 또는 목록 저장 후 종료되어도 다음 잠금 해제에서 중복 없이 마무리한다.
- 취소 기록과 실제 시스템 작업을 대조하여 작업이 없는 잔여 파일을 정리한다. 취소한 가져오기 기록은 복구 대상에서 제외한다.
- 전체 삭제는 시스템 전송의 취소 완료를 기다린다. 5초 내에 완료되지 않으면 완료로 표시하지 않고 재시도를 안내한다.
- 저장 목록의 보호된 복제본을 유지한다. JSON 손상 시 사용자가 설정에서 복구를 실행하며, 손상 원본은 보호된 Recovery 폴더에 보존한다. 복제본이 없으면 최종 일반 영상 파일로 목록을 재구성한다. 남아 있는 참조가 없는 HLS 패키지의 자동 복원은 보장하지 않는다.
- 저장 작업 복구 버튼으로 공간 부족 등으로 보류한 가져오기를 재실행한다. 앱 데이터 삭제 시 복제본과 Recovery 사본도 삭제한다.
- 전경 다운로드 감시는 화면에서 다운로드 관리자로 이동했다. HLS 시간 범위 콜백에서도 여유 공간을 검사한다. 앱이 정지된 동안의 전송과 저장공간 처리는 iOS가 관리하므로 200 MiB 여유 공간의 실시간 보장을 의미하지 않는다.
- 공개 시스템 전송은 일시정지/계속 받기를 지원하며 일시정지 의도를 기록한다. 취소·실패 후 재시도는 새 작업이다. 비공개 WebKit 전송의 재개 데이터는 디스크에 저장하지 않는다.
- 오프라인 플레이어는 playback/moviePlayback 오디오 세션을 사용한다. 화면 비활성화 시 재생을 종료하고, 오디오 인터럽트·이어폰 분리 시 일시정지한다.
- HTTP 인증/만료/제한 오류와 네트워크/시간 초과/인증서 오류를 구분한다. 오류 안내에 원본 URL·토큰을 출력하지 않는다.
- 현재 문서의 video/source와 직접 영상 링크를 읽어 저장 후보를 표시한다. 요청은 사용자가 저장 메뉴를 열 때만 수행하며 외부 서비스로 페이지를 보내지 않는다. HTTPS 주소만 허용한다. 다른 출처 프레임, DRM 및 blob/MSE 영상의 추출은 지원하지 않는다.
- 웹 JavaScript 알림·확인·입력 창에 요청 사이트를 표시한다. 탭 변경·종료·잠금 시 대기 중 응답을 취소한다.
- HLS 최대 높이와 한국어/영어/일본어 오디오·자막 선택을 제공한다. 해당 언어가 없으면 다운로드 시작 전에 실패를 알린다. 더 다양한 언어와 실제 트랙 이름을 나열하는 UI는 후속 개선 대상이다.
- 앱이 참조하는 HLS 패키지를 저장 사용량에 포함한다. 시스템 전송 캐시 등 참조 밖의 파일은 별도다.

## 보안 범위

백그라운드 URLSession은 리디렉션을 자동으로 따라간다. 사전 검증과 완료 후 URL 검증은 네트워크 목적지 전체를 강제하는 방화벽이 아니다. 다운로드 화면에 이 한계를 표시했다. HLS도 시스템이 다시 읽는 목록과 하위 요청까지 앱에서 모두 가로채지는 못한다. 신뢰하는 공개 공급자에만 사용한다.

엄격한 목적지 제한을 보장하는 HLS 엔진을 새로 추가하지 않았다. 기존 AVFoundation 경로의 제약을 숨기지 않으며 DRM 우회도 하지 않는다.

## 자동 검증

`scripts/build-ios.sh`에서 다음을 실행한다.

1. URL·파일 헤더·HLS 정책 및 오류 분류 검사.
2. 실제 임시 디렉터리를 사용하는 9개 저장 복구 시나리오: 이동 전 종료, 이동 후 종료, 목록 커밋 후 종료, 취소된 기록 제외·삭제, 손상 목록의 백업 복구, 백업 없는 파일 목록 재구성, 구버전 작업 기록 호환성, 경로 이탈 거부, 여러 항목 중 일부만 복구될 때의 일관성.
3. Swift 컴파일 경고를 오류로 취급하는 iPhone Release 빌드 및 unsigned IPA 생성.

Swift 기반 검사는 macOS에서 실행한다. Windows에는 Xcode가 없으므로 GitHub Actions의 iPhone build를 사용한다. 코드 경로를 검증하는 저장소 테스트는 iOS 파일 보호의 실기기 검증을 대신하지 않는다.

## iPhone 인수 확인

| 시나리오 | 통과 기준 |
|---|---|
| 무음 모드에서 저장 영상 재생 | 소리 출력, 화면 잠금 시 재생 중단 |
| 통화·이어폰 분리 | 갑작스러운 스피커 재생이나 자동 재개 없음 |
| 전송 중 일시정지→재실행→계속 받기 | 일시정지 의도 유지, 시스템 작업과 표시 일치 |
| HLS 한국어 오디오·영어 자막 선택 | 제공되는 트랙 다운로드 후 비행기 모드 재생 가능 |
| 존재하지 않는 언어 선택 | 기본 언어로 몰래 대체하지 않고 안내 |
| 알 수 없는 크기 전송 중 탐색 화면 유지 | 저장함을 열지 않아도 용량 검사 실행 |
| 전송 취소 직후 종료·재실행 | 취소된 항목을 저장함에 재등록하지 않고 잔여물 정리 |
| 저장 이동·목록 갱신 사이 강제 중단 | 파일 유실·중복 등록 없음 |
| 전체 삭제 중 늦은 완료 콜백 | 정리가 끝나기 전 삭제 완료로 표시하지 않음 |
| 웹 confirm/prompt·탭 전환·잠금 | 올바른 출처 표시, 콜백 정확히 한 번 종료 |

초기 iOS 18과 사용하는 iPhone의 iOS 버전 모두에서 확인한다. Face ID와 잠금 중 Data Protection, 시스템 HLS 전송은 시뮬레이터만으로 승인하지 않는다.
